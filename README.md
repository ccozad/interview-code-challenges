# Overview
 This repo has notes and implementations for various interview code challenges.

 # Easy Problems

 - [Array Intersection](/ArrayIntersection/): Find the unique elements that appear in two arrays 
 - [Is Anagram](/IsAnagram/): Determine if two strings have the same letters in a different order
 - [Matrix Add](/MatrixAdd/): Add two matrices
 - [Plus One](/PlusOne/): Add one to an arbitrary size integer
 - [Two Sum](/TwoSum/): Find numbers that add to a target number in an array
 - [Valid Brackets](/ValidBrackets/): Determine if a string has valid brackets
